EMBERSECT is a strategic xianxia tower-defense game where you command immortal cultivators, channel spiritual energy into defensive formations, trigger realm breakthroughs, and repel relentless waves of demonic beasts attacking the Sacred Spirit Altar across 10 perilous nights.

## Controls

- **1 / 2 / 3**: Select cultivator type (Sword Cultivator, Talisman Master, Formation Keeper)
- **Left Click**: Place cultivator on buildable tiles or select placed cultivators
- **Right Click**: Sell/dismiss cultivator
- **G**: Expand the protective formation array (costs spirit stones)
- **F**: Trigger cultivation breakthrough on selected cultivator
- **Space**: Start next wave / advance night
- **P**: Pause / Resume
- **M**: Mute audio

## Signature Mechanics

- **Protective Formation (Glow & Radius)**: Expand your sect's spiritual array to boost cultivator power and range.
- **Breakthrough**: Push cultivators to higher cultivation realms (Qi Refining, Foundation Establishment, Golden Core, Nascent Soul) for massive combat buffs.
- **Spirit Wisps**: Harvest drifting spiritual energy after defeating demons to fuel sect growth.
- **Formation Synergies**: Position specific cultivation arrays adjacent to one another to unlock powerful combat synergies (e.g., Flying Sword Formation).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
